API quick start

Authenticate from a terminal:

curl -X POST {{ request.scheme }}://{{ request.get_host }}/api/v1/auth/token/ \
  -H "Content-Type: application/json" \
  -d '{"username":"you","password":"…"}'

Then call an endpoint:

curl {{ request.scheme }}://{{ request.get_host }}/api/v1/me/ \
  -H "Authorization: Bearer cf_…"
